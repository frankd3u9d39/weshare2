03 / How it worksAbout a minute to set up

Three steps, then it just runs.

The PC runs a small private server on your network. Your phone talks to it directly, the same way it would talk to a printer or a TV on the same Wi-Fi.

01

Install on your PC

Run the installer and open Weshare. When Windows asks about the firewall, allow it on Private networks so your phone can reach it.

02

Connect your phone

On the same Wi-Fi, scan the QR code. The browser warns about Weshare's private certificate the first time; continue past it, then type the PIN.

03

Send and accept

Pick files or a folder and press Send. The other side taps Accept all and you can watch it arrive on both screens.

04 / SecurityWhat protects your files

Private by default, not by setting.

Weshare never sees your files. They travel between your own devices, encrypted, and only to the device you sent them to. Here's exactly what's in place.

Connection HTTPS and secure WebSockets with a certificate made on your PC, so traffic is encrypted even on shared Wi-Fi.
Pairing 6-digit PIN shown on the PC. Repeated wrong guesses are locked out.
Who can download Only the device a file was sent to, and only after it accepts.
Shared folders Read-only, and only for phones you've chosen to remember.
Updates Published on GitHub and checked against GitHub's SHA-256 before they install.
Accounts None. No sign-up, no email, no login.
05 / QuestionsThe ones we get most
Q.01Do I need internet for this?+

No. Both devices only need to be on the same Wi-Fi network. Transfers keep working when the router has no internet connection at all.

Q.02Why does my phone warn me about the connection?+

Weshare encrypts everything with a certificate made on your own PC rather than one bought from a certificate company, so the browser doesn't recognise it the first time. That's expected. Tap Advanced and continue, then enter the PIN.

Q.03Windows says "Windows protected your PC". Is it safe?+

The installer isn't code-signed yet, so Windows SmartScreen doesn't know it. Click More info then Run anyway.

If you'd like to be sure the file is ours, compare its SHA-256 with the one on the release page.

Q.04My phone can't find the PC.+

Check that both are on the same Wi-Fi (not a guest network), and that Weshare is allowed on Private networks in Windows Firewall. If your PC's network is set to Public, switch it to Private in Windows settings.

Q.05Can I send a folder from my phone?+

Most phone browsers can only pick files, not folders. Zip the folder in your phone's file app and send the zip; Weshare unpacks it back into a folder on the PC. You can turn that off in Settings.

Q.06Is there a Mac or Linux version?+

Not for 1.1 yet. The desktop app currently ships for Windows 10 and 11. The phone side works on any phone with a modern browser.
